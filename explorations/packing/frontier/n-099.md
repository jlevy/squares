# `s(99)` — solved

`s(99) = 10`. Established by Nagamochi’s general theorem, Hiroshi Nagamochi (2005).
General closed form: s(N) >= min(ceil(sqrt(N)), sqrt(N - 2*floor(sqrt(N)) + 1) + 1).

## The packing

The record catalogue does not picture `n = 99`: no arrangement has ever been found that
beats the trivial `⌈√99⌉ = 10` grid, so the grid is still the best known packing.
That is a statement about what has been searched, not a proof.

## The lower bound

Nothing specific to this `n` has ever been proved.
The bound is Nagamochi’s general closed form, which applies to every `N ≥ 4`:

```
s(N) ≥ min{ ⌈√N⌉,  √(N − 2⌊√N⌋ + 1) + 1 }
```

This is the default across almost the whole open frontier — 63 of the 65 open cases at
`n ≤ 100` are governed by it, and it has not been improved since 2005.
