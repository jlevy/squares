# `s(25)` — solved

`s(25) = 5`. Established by triviality (a perfect square).

## The packing

The record catalogue does not picture `n = 25`: no arrangement has ever been found that
beats the trivial `⌈√25⌉ = 5` grid, so the grid is still the best known packing.
That is a statement about what has been searched, not a proof.

## The lower bound

`25` is a perfect square, so the `5×5` grid is optimal and the area bound `√n` is
already tight.
