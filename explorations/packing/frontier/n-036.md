# `s(36)` — solved

`s(36) = 6`. Established by triviality (a perfect square).

## The packing

The record catalogue does not picture `n = 36`: no arrangement has ever been found that
beats the trivial `⌈√36⌉ = 6` grid, so the grid is still the best known packing.
That is a statement about what has been searched, not a proof.

## The lower bound

`36` is a perfect square, so the `6×6` grid is optimal and the area bound `√n` is
already tight.
