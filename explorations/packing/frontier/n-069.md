# `s(69)` — open

Open. The best known published packing gives `s(69) ≤ 8.8272055078159206569…`, and the
best proved lower bound is `8.348469` from Nagamochi’s general theorem, leaving a gap of
`0.4787`. General closed form: s(N) >= min(ceil(sqrt(N)), sqrt(N - 2*floor(sqrt(N)) + 1)
\+ 1).

## The packing

The UnitSquare Project’s 29 July 2026 release improves the public Morandi-Cantrell
parent by `0.000006548113079343119`. The old parent’s degree-82 polynomial does **not**
describe this smaller numerical construction and has therefore been removed from the
current-bound fields.
The release reports interval, 300-digit, and independent-checker validation, but that
validation has not been independently re-run here.

## The lower bound

Nothing specific to this `n` has ever been proved.
The bound is Nagamochi’s general closed form, which applies to every `N ≥ 4`:

```
s(N) ≥ min{ ⌈√N⌉,  √(N − 2⌊√N⌋ + 1) + 1 }
```

This is the default across almost the whole open frontier — 63 of the 65 open cases at
`n ≤ 100` are governed by it, and it has not been improved since 2005.
