# `s(68)` — open

Open. The best known published packing gives `s(68) ≤ 8.8033830747161083869…`, and the
best proved lower bound is `8.28011` from Nagamochi’s general theorem, leaving a gap of
`0.5233`. General closed form: s(N) >= min(ceil(sqrt(N)), sqrt(N - 2*floor(sqrt(N)) + 1)
\+ 1).

## The packing

The UnitSquare Project’s 29 July 2026 release improves the public
Brendberg-Schadt-Ellsworth parent by `0.0000768618004216131`. The release classifies the
result as a construction-only upper bound and reports outward-rounded interval
validation, a 300-digit zero-tolerance recomputation, and an independent published
checker. This repository has checked the release record and its hashes, but has not yet
independently re-run that validation; `verified_here` therefore remains empty.

## The lower bound

Nothing specific to this `n` has ever been proved.
The bound is Nagamochi’s general closed form, which applies to every `N ≥ 4`:

```
s(N) ≥ min{ ⌈√N⌉,  √(N − 2⌊√N⌋ + 1) + 1 }
```

This is the default across almost the whole open frontier — 63 of the 65 open cases at
`n ≤ 100` are governed by it, and it has not been improved since 2005.
