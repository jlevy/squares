# `s(81)` — solved

`s(81) = 9`. Established by triviality (a perfect square).

## The packing

The record catalogue does not picture `n = 81`: no arrangement has ever been found that
beats the trivial `⌈√81⌉ = 9` grid, so the grid is still the best known packing.
That is a statement about what has been searched, not a proof.

## The lower bound

`81` is a perfect square, so the `9×9` grid is optimal and the area bound `√n` is
already tight.
