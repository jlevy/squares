This directory retains the completed n68, n84 and n85 stage-4 mathematical audits and
their authentic execution context.

producer’s `sqverify_fast` components apart from the declared-net readers.

They are neither universal coverage verifiers nor proof-assistant certificates.

## Historical Reproduction and Independence

The mapped reviews preserve the complete commands and read logs.
The retained `env.sh.txt` files preserve the original existing Python 3.14.7 and
four-source-root settings.
To inspect the original import closure, restore the `.py.txt` basenames to `.py` in a
private external scratch copy while preserving these two sibling directories.
The n84/n85 driver locates its n68 helpers relative to its own file.
Choose new output paths.

Those commands also require the original checkpoint directory, preserved executable and
original source context: the historical drivers compare that context with Git and
require its recorded identity.
The records preparation did not rerun those comparisons against today’s modified
reporter, create a portable adapter, or invent a new acceptance run.
The authentic PASS receipts record the actual completed comparisons.
The registered evidence does not gate on today’s source revision.

The reviewers read the source mathematics, soundness exposition, maintained driver and
prior platform/n68 reviews before evaluating these cases.
Their standard-library point integrator was written separately and shares no producer
code, but its authors had read maintained code, so `clean_room` is false.
The n84/n85 audit reuses the named n68 helpers, which is explicitly recorded.
The producer discloses AI assistance without identifying every authoring system; overlap
is unknown. The deciding native replay shares the producer’s crate.
Separate point calculations do not convert it into an independent full implementation or
another method.
