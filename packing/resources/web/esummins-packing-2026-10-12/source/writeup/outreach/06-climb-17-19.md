## 3. The climb rule — Lemma K1 run forward (`code/root243.py`, `descend243.py`, `climb243.py`)

Page of a class S: pins at S's slots, each an upright box of half-width d = (λ_max − 1)·max(u, v) with exact core
½ − d; H = ONE non-pin square anywhere (vacuous: n − k ≥ 1); n − k − 1 anonymous squares; pad "window".
The dichotomy (Theorem FC / SLOT-CROWD, `02` §2): for a candidate cell p (Young-completable, unclipped, inside) with
T_p = S + p, either p's open slot box is met by ≥ 2 non-pin squares, or the teleport gives a packing at the SAME
side containing T_p's pins.  Hence

    dead(S)  ⇐  dead(S with every candidate cell doubly met)  ∧  dead(T_p) for every p.

The SPINE node `S__spine` assumes the first horn at every candidate cell; its verdict is **DEAD** (spine closed and
every T_p DEAD on the table: S is closed on the window), **REDUCES → {T_p open}** (spine closed, some T_p not dead:
every packing of S contains the pins of one of those T_p — the climb's k + 1 branches), or **ALIVE** (the spine did
not close in its wall; nothing claimed).  The descent decides k = 16 → k_stop so that every T_p is decided before S
runs; a DEAD T_p is CITED, never re-solved.  The climb from the four-corner root is read off the table: root =
`n17_k04_0016`; a REDUCES node's children are its open T_p; leaves are DEAD / ALIVE / the record's k.  Since a
superset of the four corners contains the four corners, the four-corner classes are closed under extension: the
descent restricted to them (`--corners4`) is exactly the climb's node set.

**Soundness statement.**  A DEAD branch is the theorem: *no packing of n unit squares in a square of side
m ∈ [s_lo, s_hi] contains axis-aligned unit squares at the slots of that class (all D4 images)*, proved by the A211
coarse tree's leaf lemmas (EmptyBox / FC / REACH / NOROOM(-CN) / CC / SNAP into a DEAD stratum, each n-general) on
the page above, with every FC cell either forced by a DEAD extension (cited) or assumed on the spine and paid for by
the REDUCES targets.  Kills are `[C: closed-form / library clip trace]`, no verifier clause — as at n = 11 (`05` §6).
**Canary**: the record realises its class and every class it contains inside the window, so none of those may ever
be DEAD; `climb243.canaries` checks it on every report (OK on every report so far).
