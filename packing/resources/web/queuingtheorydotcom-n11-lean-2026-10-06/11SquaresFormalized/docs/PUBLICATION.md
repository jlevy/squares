# Publication and privacy

This integration preserves 11SquaresFormalized's existing Git history. New
integration commits use the generic project identity **Square Packing
Contributors** and **contributors@users.noreply.github.com**. Existing public
contributor and third-party license credits are retained.

The tracked tree includes source, certificates, public provenance, verification
tooling, and portable final-audit evidence. It excludes raw compiler diagnostics,
local build caches, private archives, conversation records, credentials, and
personal machine paths. The completed-run evidence contains mathematical names,
source hashes, build pins, and public repository/run identifiers.

The workflow is manually dispatched with read-only repository and Actions
permissions. Its downloadable diagnostic artifacts may contain runner paths;
inspect them before sharing. These expiring artifacts are separate from the
portable source tree. Keep `.lake/` and `.verification/` ignored.

A generic commit identity does not hide GitHub's repository ownership or account
activity, and this update does not rewrite previous public commits.
