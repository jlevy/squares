This file records what has been checked for the frozen `4.456575` package.


The exact point coordinates are in
`certificates/lower_bound_4p456575/points.json` and are duplicated as constants
inside each verifier so that certificate acceptance does not depend on parsing
JSON or any nonessential library.

## Exact verification

The frozen certificate has been accepted by:

1. `verify_certificate.cpp`: fast exact C++ checker;
2. `verify_certificate_bigint.cpp`: separately implemented Boost `cpp_int`
   checker;
3. `verify_certificate.py`: separately implemented Python arbitrary-integer
   checker.

All three traverse the untrusted certificate and recompute leaf claims.

## Deterministic reproduction

`generate_certificate.cpp` deterministically reconstructs the tree from the
frozen rational data and exact branch predicates. `verify_4p456575.sh` requires
the regenerated bytes to have the expected SHA-256 and to compare byte-for-byte
with the archived certificate before running the three checkers.

## Adversarial parser tests

`tests/rejection_tests.sh` checks that the fast checker rejects at least:

- a truncated certificate;
- a certificate with a trailing byte;
- an unknown opcode at the root.

These tests do not prove checker correctness, but they guard common ways a tree
parser can accidentally accept malformed data.

## Deliberately excluded

The numerical search/optimization code used to discover the points is *not* part
of the proof and is intentionally excluded. Experimental stronger leaf tests are
also excluded. The frozen theorem uses the same basic subdivision predicates as
the original `17squares` certificate architecture.
