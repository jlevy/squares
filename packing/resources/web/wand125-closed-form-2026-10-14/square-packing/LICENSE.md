# Licenses

This repository has no single license. Each top-level project folder keeps the license it was published under:

- Folders from wand125's earlier repositories: MIT (the `LICENSE` file in the folder).
- Code by other authors keeps its own license next to it, for example `UPSTREAM-LICENSE.txt` (MIT, Evan Daniel)
  in `lean/n11-optimality/` and `problems/square-lower-bounds/point_n21_L5/`, the vendored `verify.cpp`
  (tokoharu, MIT) inside the rectangle-density certificates, and `tools/THIRD_PARTY_NOTICES.md`.

If a folder has no `LICENSE`, the nearest enclosing folder's license applies.
