# Stage 4 Review of #1009: Programs, Frozen Files and Receipts

This directory keeps the programs and receipts of lane c-review-1009-1117’s blind stage
4 review of issue [#1009](https://github.com/jlevy/squares/issues/1009), Mykhailo
Polkovskyi’s thirteen exact rational certificates at 147, 156, 180, 210, 260, 262, 268,
270, 272, 292, 295, 299 and 307:
[`docs/project/reviews/review-2026-11-17-polkovskyi-1009.md`](../../../../docs/project/reviews/review-2026-11-17-polkovskyi-1009.md).

The sources are files of
[Mishapolk/square-packing-records](https://github.com/Mishapolk/square-packing-records)
at `b637e6cf59c23781c813e8442bfdccb5aa5f3954`, not retained here; the import lane retains
them in its own packet. This directory is review-only.

The review lane froze its checker and plan at 03:33:14Z and its findings at 04:28:50Z on 17
November 2026 and then stopped; this README was written afterwards, by lane
w3-pass-1117r, from the review’s text, the programs’ own usage lines and the receipts,
so that the review’s link to it resolves. It changes no program, plan, receipt or frozen
file, and the two digest lists under `frozen/` verify against them.

Each count has two files, a `.cert` file of centres and half-angle tangents (form P) and
a Witness/v2 file of rational corners (form C).

## Layout

- `programs/`: the review’s programs, the controls plan (`controls-plan.json`) and the
  issue’s saved REST response (`issue-1009.json`, fetched at 01:34:03Z).
- `frozen/`: the checker’s and the plan’s digests at their freeze
  (`checker-frozen-digests.txt`), the findings’ digest at their freeze
  (`findings-frozen-digest.txt`), and the frozen review text.
- `out/`: the receipts.

## Programs

Every program is the review lane’s own, written for this review as a clean-room
implementation: it imports nothing from this repository or the source, and reuses no
code of any earlier review.
The review of #1001 (lane L186) was the model; its text, its packet’s README and its
frozen lists were read, and its programs were not opened.
Each was run with CPython 3.14.7 (the project interpreter) as `python -I -B`, under
`nice -n 19`.

| Program | Decides | Writes |
| --- | --- | --- |
| `rv1009_reader.py` | the strict readers of form P and form C; every scalar `p` or `p/q`, handed out as written and not reduced | nothing (a module) |
| `rv1009_axes.py` | method A: separating axes in Python integers, from poses | nothing (a module) |
| `rv1009_clip.py` | method B: exact convex clipping in GMP rationals, from corners alone | nothing (a module) |
| `rv1009_forms.py` | nothing about a packing: each form written in the other’s terms, and whether two listings are the same square | nothing (a module) |
| `rv1009_decide.py` | a packing by both methods, every square, wall and pair, with no distance filter and no tolerance | nothing (a module) |
| `rv1009_files.py` | one count’s two files to a decision, natively and crossed, with the twin relation | nothing (a module) |
| `rv1009_geom.py` | nothing: closed forms and moves for the self-test and the controls | nothing (a module) |
| `rv1009_write.py` | nothing: writers of both forms, for the controls | nothing (a module) |
| `rv1009_issue.py` | nothing: the issue’s three tables, read from its saved response | nothing (a module) |
| `rv1009_check.py` | one count’s two files against the issue’s digests and claim, each file decided by both methods | `out/check-nNNN.json` |

| `rv1009_controls.py` | the 37 controls of the plan at one count, by both methods or the readers | `out/controls-nNNN.json` |

From `packing/` of this repository, with `PIN` a checkout of the source at the pin and
`R` this directory, for each count `N`:

```bash
PY="nice -n 19 .venv/bin/python3 -I -B"
$PY $R/programs/rv1009_selftest.py $R/out/selftest.json
$PY $R/programs/rv1009_check.py $PIN/certificates/0000-0999/nN.cert \
  $PIN/witnesses/2026-11-16/n-N.yaml $R/programs/issue-1009.json N $R/out/check-nN.json
$PY $R/programs/rv1009_controls.py $PIN/certificates/0000-0999/nN.cert \
  $PIN/witnesses/2026-11-16/n-N.yaml $R/programs/controls-plan.json \
  $R/programs/issue-1009.json N $R/out/controls-nN.json
$PY $R/programs/rv1009_describe.py $PIN/certificates/0000-0999/nN.cert \
  $PIN/witnesses/2026-11-16/n-N.yaml $R/programs/issue-1009.json N $R/out/describe-nN.json
$PY $R/programs/rv1009_lstep.py $PIN/certificates/0000-0999/n262.cert \
  $PIN/certificates/0000-0999/n295.cert $R/out/lstep-262-295.json
```
