Squares in Squares
$s(n^2-n-1)$
 SVG, high-precision, and categorized list by David Ellsworth
based on original compiled by Erich Friedman

In April 2014, Joe DeVincentis found a pattern applying to $s(n^2\!-\!n\!-\!1)$ packings. It held the record for over a decade on $s(29)$, $s(41)$, and $s(71)$, and for a couple years on $s(131)$, but thanks to Thomas Schadt's simulated annealing program has been shown to be inoptimal for all $n \gt 3$. On this page that pattern is shown alongside the packings that beat it. For the main list, see Squares in Squares or Squares in Squares: Triangular Table View.

For odd $n$, there is a predictable ordered $s(n^2\!-\!n\!-\!1)$ pattern that continues to infinity. For even $n$, the optimal packing tends to be chaotic and unorderly. But simulated annealing has shown that odd $n$ pattern is also becomes more chaotic when optimized (although it retains symmetry).

Where the word "alternative" is used, this designates an alternative packing, which is enclosed within the same-sized bounding square as another packing, but cannot be reached by continuously translating and/or rotating the squares in that packing. When the packing can be reached by such continuous transformations, the word "rearrangement" is used. For more information on each packing, view its SVG's source code. In browsers that don't provide an easy way to do this, you can prepend the URL with "view-source:" (without the quotes).
