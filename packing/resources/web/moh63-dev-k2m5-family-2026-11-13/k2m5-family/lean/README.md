# Lean 4: `Valid11 → ∀ k ≥ 10, s(k² − 5) = k`

`K2m5/Inst.lean` proves

```
theorem k2m5_of_valid11 (h : Valid11) : ∀ k : ℕ, 10 ≤ k → minSide (k ^ 2 - 5) = k
```

where `Valid11` says that every closed unit square in [0, 11]² has mass ≥ 1 under the board file
`certificate/sol_exact_box11.txt`, read verbatim (`InstData.boxSegs`, `boxPolyVerts`, `boxPolyW`). The kernel checks
that this file is μ₁₁ of the family (`sol_exact_family.txt`), that μ_k has total k² − 4D with
D = 2681133855518/(2·10¹²) for every k ≥ 9, and the reduction for every k ≥ 10. `#print axioms` gives
`[propext, Classical.choice, Quot.sound]`. `Valid11` itself is the computer-checked statement of the paper's
Theorem 10.

* `Grid10.lean`, `Fam10.lean`: Daniel's generic family reduction (`Sqpack/BentzFam.lean`) ported to the 1/10 grid.
* `InstData.lean`: generated by `scripts/gen_fam10_data.py --box sol_exact_box11.txt --family sol_exact_family.txt
  --ns K2m5Inst` (deterministic; its header records both sha256 sums).
* `InstFam.lean`, `InstC1..C7.lean`, `Inst.lean`: the instance; each kernel check is its own module (about 6 GB each).

Build (as we did): compile Daniel's Lean project at evand/square-packing@659ee62 (`lean/`, toolchain
`leanprover/lean4:v4.33.1` and its Mathlib), put its build output on `LEAN_PATH`, and compile the modules of
`K2m5/` with `lean -o` one per process in this order: `Grid10 Fam10 InstData InstFam InstC1 … InstC7 Inst`. `build.log`
records our build of 12 November 2026.
