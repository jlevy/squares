FIVE-HOUR PROGRESS SAVE
The absolute deadline starts before checkout. Setup, restoration and replay
count toward five hours; the six-hour job limit leaves time to stop and upload.
Automatic CPU/memory sizing respects the available machine resources. Module
replay remains serial, with available Lean threads within each module. Local
build defaults remain conservative. During module verification, console output
is only module k/total; detailed compiler messages are retained in artifacts.

At the deadline, completed objects and receipts are saved to this repository's
Actions cache. Each run also uploads n12-final-build-ATTEMPT and
n12-final-evidence-ATTEMPT artifacts, retained for 30 days. Build upload includes
the whole compiler output directory, including Lean 4.35 sidecars. A hard manual
cancellation or runner loss can prevent saving; let the scheduled stop happen.

RESUME AND TRUST
resume_run=auto restores the latest compatible full build cache. none skips
cache restoration. fresh=true forces every project module to be checked again.
Numeric run IDs and old .olean-only checkpoint restoration are disabled here,
because they cannot restore all possible Lean 4.35 sidecars. Downloadable old
checkpoints still preserve the historical compiled objects and their receipts.
Upstream's private cache is not automatically available in this repository.

Every reused module is checked against source/dependency/compiler fingerprints,
object hashes, log hashes and admission-free successful receipts. A cache hit
alone does not establish the theorem. Changed sources and their dependents are
rechecked. Interrupted modules restart from the beginning. Global-success reports
are reset before cache restoration and never accepted from an older run.

A scheduled stop can be a successful job that saved only partial progress.
Read its summary and github-replay.json. Full acceptance requires final profile,
all 5,377 project modules, exact type S12.packingConstant12 = 4, and final axiom
audit. The recorded inventory is 9,583 modules including libraries/setup/audit,
under the hard 10,000 cap. The native classification retains compiler trust.
