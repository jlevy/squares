## Bounds from repeated strips

A unit square projects to an interval of width at most √2 on each axis. Three identical central strips on the anchor board capture every local configuration that occurs when more strips are inserted. The same proof covers several board sizes. Exact strip and cell masses give the square count at each new size. The proof and its replay are in followup/repeated.

## Reduced corner mass on a periodic board

Reweighting the four corners changes the total mass of the board. Only unit squares that can meet a changed corner need a second coverage proof. The exact weights, local center and angle checks, and repeated-strip arithmetic are in [the corner proof](followup/corner_trim/PROOF.md).

Each proof uses a nonnegative rectangle measure. The whole board has less mass than the number of squares to be packed, and every permitted unit square covers at least one unit of mass. The verifier covers the full range of centers and orientations. Sources, rational transformations and accepted interval checks accompany the table.

## Reproduction

Run `python3 followup/verify.py` from the extracted archive to rebuild the new measures, check the certificates and verify every upper-bound pair. Run `python3 followup/verify.py --n 114 --replay --workers 4` to recompute the individual center subdivisions and negative controls for 114 squares. Run `python3 verify.py` to check the whole archive. Full lower-bound replay requires a C++17 compiler. The verification code uses the Python standard library.

Public comparisons used the SquareMath repository at revision 1015fc175fa4e2c01f912d915d784100e36d3bab and Kaggle leaderboard version 38 (session 371230297). These certificates were prepared locally.
