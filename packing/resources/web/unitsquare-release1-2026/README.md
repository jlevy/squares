# UnitSquare Results Release 1

First-party snapshot of the UnitSquare Project’s 29 July 2026 results release,
retrieved from <https://hmbelvedere.com/> on 25 August 2026.

- `results.html` is the public reader-facing release page.
- `results.json` is the public structured release record.

The release reports improved upper bounds at `n = 68, 69, 103, 105, 110, 131` and
explicitly makes no optimality claim. It describes outward-rounded interval validation,
a 300-digit numerical recomputation, and an independent use of Schadt’s checker. The
public files do not contain the referenced interval receipts, interval boxes, or a
replayable interval checker. The frontier therefore records these as source reports,
not as external or repository verification.

The JSON contains hashes supplied by the source. They are retained because this is an
unaltered source snapshot; this repository does not use or repeat them as mathematical
evidence.
