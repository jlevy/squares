## Acquisition and Comparison

[The acquisition manifest](acquisition/sources.json) records each pinned URL, source
SHA-256 digest and byte count, exact side, derived-facts path and seed. Its digest reader
is `check --source`, which compares the external pinned JSON against the manifest and
normalized facts. [The frontier comparison](acquisition/frontier-comparison.json) keeps
all twelve previous reported bounds and their attribution, captured from the structured
case records before this registration. It is an independent historical snapshot, not
regenerated by acquisition against the now-updated frontier. `check` validates its
roster, new sides and seed identities, verifies strict improvement over previous
reported displays, and matches the five exact predecessors to the original packet.
[The n153 comparison](acquisition/n153-comparison.json) compares the exact side and every
ordered rational half-angle triple to the original attachment facts. A distinct
acquisition packet supplies current repository provenance without overwriting that
attachment's historical provenance or its certified receipts.

From `packing/`:

```bash
uv run --frozen python -m devtools.squish_followup_packets acquire --source PATH
uv run --frozen python -m devtools.squish_followup_packets check --source PATH
uv run --frozen python -m devtools.squish_followup_packets check
```

`PATH` is the pinned source's `squish-submission-2026-10-07` directory. Acquisition uses
the original bounded rational parser and retains all thirteen complete rosters. The
checks establish source identity and normalized-record consistency; neither runs the
producer checker nor establishes feasible geometry. Complete deciding replay and new
scoped review are the next entry under think-oxvk. The current atlas draws the twelve
update geometries and checks exact feasibility at the drawing boundary; that check does
not promote the imported result. Earlier certified bounds, source packets, receipts and
reviews remain unchanged while these tighter claims await retained confirmation.
