# `s(34)` — solved

`s(34) = 6`. Established by Nagamochi’s general theorem, Hiroshi Nagamochi (2005).
General closed form: s(N) >= min(ceil(sqrt(N)), sqrt(N - 2*floor(sqrt(N)) + 1) + 1).

## The packing

Found by Hiroshi Nagamochi in 2005, via a hand construction.

## The lower bound

Nothing specific to this `n` has ever been proved.
The bound is Nagamochi’s general closed form, which applies to every `N ≥ 4`:

```
s(N) ≥ min{ ⌈√N⌉,  √(N − 2⌊√N⌋ + 1) + 1 }
```

This is the default across almost the whole open frontier — 58 of the 65 open cases at
`n ≤ 100` are governed by it, and outside this repository’s own displacements it has not
been improved since 2005.
