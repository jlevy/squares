# `s(18)` — open

Open. The best known packing gives `s(18) ≤ 4.82287566`. The verified lower bound is
`s(18) ≥ 187/40 = 4.675`, from this repository’s weighted fractional unavoidable-set
certificate at that side (`T-028`, 2026-09-19, `V4/C4`), leaving a bound gap of `0.1479`
to the reported record.
It is not inherited by monotonicity.
Only `Condition 2` of the five mentions `n`, so an atom set of total mass
`35758287/2000000 = 17.8791435` certifies its side for every integer strictly above that
mass — 18 and upward.
The bounds it superseded: this repository’s own `467/100 = 4.67` (`T-027`, 2026-09-18),
which held until 2026-09-19; `459/100 = 4.59` (`T-019`, 2026-09-04), which still holds
n = 17; the selected external report `9141/2000 = 4.5705`; the `n = 17` Massaccesi
certificate’s `22529/5000 = 4.5058`, carried here by monotonicity as `T-016`; the
first-party sixteen-point certificate’s `4.426213` (`T-002`); and Nagamochi’s general
`4.316625` (closed form:
`s(N) >= min(ceil(sqrt(N)), sqrt(N - 2*floor(sqrt(N)) + 1) + 1)`).

## The packing

Hämäläinen’s 1980 packing, at the tilt `arcsin((sqrt(7) − 1)/4)` DS7 names exactly, for
which the survey states the angle but no generating rule.
`cases/lifted_q7` lifts the retained witness’s every coordinate into `Q(sqrt 7)` at
small height — the repository’s first exact verification outside `Q(sqrt 2)` — and
verifies the lifted pose exactly, which is what moved `verified_upper_bound` from the
grid ceiling onto the published exact side.
The lift is a candidate generator and the exact verifier is the proof (`D-398`, and the
operation `D-402` does not foreclose).

## The lower bound

The selected external report, [GitHub n17 certificates 2026], gives the lower-bound
expression `9141/2000` for `s(18)` (approximately `4.5705`). The indexed external v0.2.0
report states s(17) >= 9141/2000 = 4.5705; the source checker has not been replayed
completely here. Inherited at n=18 by monotonicity.
This changes the reported source field only; the independently verified lower bound is
`4.675`. The [source audit](../devtools/audit_ds7_lower_bounds.py) compares the exact
theorem expressions separately from opaque table decimals.

David R. MacIver’s manuscript dated 8 August 2026 separately reports
`s(18) ≥ s(17) > (40sqrt(2)+19)/17 + 1/200 ≈ 4.450208382054341`, in Corollary 1.2. The
[archived source review](../resources/web/maciver-square-packing-2026-09-07/README.md)
records it as a historical claim whose essential certificate and replay files are absent
from the inspected public snapshot.
It does not change the stronger verified bound below.

The operative bound is this repository’s own
[T-028 certificate](../cases/n18_fractional_certificate/certificate.json) at side
`187/40`: 725 rationally weighted atoms on a `D4`-symmetric site set, total mass
`35758287/2000000 = 17.8791435 < 18`, every closed `B`-square at every net
direction capturing mass at least one, the least being `4000013/4000000`. It is decided
from its own bytes by an exact event-cell sweep and by an interval branch and bound over
centre boxes, which agree on that least value to the digit.
The site set is BC-191 auto grids `(32, 43, 53)` unioned with T-027’s 769 atom sites
scaled from `467/100` to `187/40`, plus a windows-5 lattice. The row loop never crossed
18 and converged.
No monotonicity step is involved and none is needed: the covering program the search
solves does not contain `n` at all, and `Condition 2` — total mass strictly below `n` —
is the only place `n` enters, so the same atoms certify the side at every size above
their own mass. The certificate does not reach n = 17, whose mass must sit strictly
below 17; T-019 still holds that case at `459/100`. From n = 19 on the register already
holds `24/5 = 4.80` (T-020), so this certificate is true there and weaker.
A run at `117/25 = 4.68` drove three historical site sets in succession, 538, 578 and
618 orbits, and each returned a restricted optimum of exactly `18.000000`. The T-019
seed that previously certified `467/100` as T-027 locked at `18.000000` there too, as
did T-027’s own atoms. Adding sites can still lower a restricted optimum, so `117/25`
is not barred.
Two weaker bounds are retained for provenance: T-027’s `4.67`, which held this case
until 2026-09-19, and T-019’s `4.59` below it, which held until 2026-09-18.
Nagamochi’s general closed form remains the external published baseline and applies to
every `N ≥ 4`:

```
s(N) ≥ min{ ⌈√N⌉,  √(N − 2⌊√N⌋ + 1) + 1 }
```

It is weaker here than the verified `4.675` bound recorded above.
