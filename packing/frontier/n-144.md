# `s(144)` — solved

$s(144) = 12$. Established by triviality (a perfect square).

## The packing

The record catalogue does not picture $n = 144$: no arrangement has ever been found that
beats the trivial $\lceil\sqrt{144}\rceil = 12$ grid, so the grid is still the best
known packing. That is a statement about what has been searched, not a proof.

## The lower bound

$144$ is a perfect square, so the $12\times12$ grid is optimal and the area bound
$\sqrt{n}$ is already tight.
