# `s(38)` — open

Open. The best known packing gives `s(38) ≤ 6.70710679`, and the strongest lower bound
independently verified here is `6.196152` from Nagamochi’s general theorem, leaving a
gap of `0.511`. General closed form: s(N) >= min(ceil(sqrt(N)), sqrt(N -
2*floor(sqrt(N)) + 1) + 1).

## The packing

Found by Frits Göbel in 1979, via a diagonal-strip construction — the strip family at
`a = 5`, whose side is `6 + sqrt(2)/2` exactly.
`cases/gobel_strip` builds it and verifies it exactly over `Q(sqrt 2)`, which is what
moved `verified_upper_bound` from the grid ceiling onto the exact side.
The retained witness declares that side rounded down at its own digits — about
`4.85e-30` below the exact value — and a different slack choice for the strip, so the
certificate carries the construction’s coordinates rather than the witness’s (`D-398`).

## The lower bound

The selected external report, [Friedman DS7], gives the lower-bound expression
`10*sqrt(3)/37 + 2*sqrt(2) + 113/37` for `s(38)` (approximately `6.350603018684`).
Friedman’s DS7 survey, Theorem 9, k=6, reports this bound at n=37; reference [8] is
Green’s private communication (2000). The source proof has not been recovered.
Inherited at n=38 by monotonicity.
This changes the reported source field only; the independently verified lower bound
remains `6.19615242271`. The [source audit](../devtools/audit_ds7_lower_bounds.py)
compares the exact theorem expressions separately from opaque table decimals.

The strongest lower bound independently verified in this record is Nagamochi’s general
closed form, which applies to every `N ≥ 4`:

```
s(N) ≥ min{ ⌈√N⌉,  √(N − 2⌊√N⌋ + 1) + 1 }
```

At `n ≤ 100`, this theorem supplies the independently verified lower bound in 58 of the
65 open cases. Source-reported bounds are recorded separately.
