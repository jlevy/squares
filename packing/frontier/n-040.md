# `s(40)` — open

Open. The best known packing gives `s(40) ≤ 6.82842713`, and the strongest lower bound
independently verified here is `6.385164` from Nagamochi’s general theorem, leaving a
gap of `0.4433`. General closed form: s(N) >= min(ceil(sqrt(N)), sqrt(N -
2*floor(sqrt(N)) + 1) + 1).

## The packing

Found by Frits Göbel in 1979, via a hand construction.
The catalogue flags it **rigid**: no continuous deformation is possible, so the contact
conditions pin the side length exactly as an algebraic number.

## The lower bound

The selected external report, [Friedman DS7], gives the lower-bound expression
`2*sqrt(2) + 8*sqrt(5)/5` for `s(40)` (approximately `6.406135888746`). Friedman’s DS7
survey, Theorem 10, k=6, reports this bound at n=40; reference [8] is Green’s private
communication (2000). The source proof has not been recovered.
This changes the reported source field only; the independently verified lower bound
remains `6.38516480713`. The [source audit](../devtools/audit_ds7_lower_bounds.py)
compares the exact theorem expressions separately from opaque table decimals.

The strongest lower bound independently verified in this record is Nagamochi’s general
closed form, which applies to every `N ≥ 4`:

```
s(N) ≥ min{ ⌈√N⌉,  √(N − 2⌊√N⌋ + 1) + 1 }
```

At `n ≤ 100`, this theorem supplies the independently verified lower bound in 58 of the
65 open cases. Source-reported bounds are recorded separately.
