# `s(140)` — open

Open. The best known packing gives `s(140) ≤ 12`, and the strongest lower bound
independently verified here is `11.908712` from Nagamochi’s general theorem, leaving a
gap of `0.0913`. General closed form: s(N) >= min(ceil(sqrt(N)), sqrt(N -
2*floor(sqrt(N)) + 1) + 1).

## The packing

The record catalogue does not picture `n = 140`: no arrangement has ever been found that
beats the trivial `⌈√140⌉ = 12` grid, so the grid is still the best known packing.
That is a statement about what has been searched, not a proof.

## The lower bound

The strongest lower bound independently verified in this record is Nagamochi’s general
closed form, which applies to every `N ≥ 4`:

```
s(N) ≥ min{ ⌈√N⌉,  √(N − 2⌊√N⌋ + 1) + 1 }
```

Source-reported bounds are recorded separately from this independently verified theorem.
