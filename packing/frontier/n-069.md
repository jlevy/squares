## The verified upper bound is a ceiling

`verified_upper_bound` for this case is $9$, which is **larger** than the best known
$8.827205507815920656880680735618736931225314831$ two fields above it.
It is not a tighter reading of the same packing and it is not the value of $s(69)$: it
is the strongest ceiling this repository can certify from its own evidence — the trivial
grid bound $\lceil\sqrt{69}\rceil = 9$ — and it trails the reported construction by
$0.1727944921840793431193192644$.

Its `exact_form` is the exact form of that ceiling, never of $s(69)$. $s(69)$ is not
known exactly; `status` stays `open`, and the `mathematics` blocker in the frontmatter
names the gap. Read `reported_upper_bound` for the best known side length.

## The packing

The UnitSquare Project’s 29 July 2026 release improves the public Morandi-Cantrell
parent by $0.000006548113079343119$. The old parent’s degree-82 polynomial does **not**
describe this smaller numerical construction and has therefore been removed from the
current-bound fields.
The release says it used interval arithmetic, a 300-digit recomputation, and an
independent checker.
It does not publish the interval boxes, governed receipt, or replayable checker needed
to inspect the formal claim.
We therefore record the value as reported.
