Packing unit squares in a square

A mockup standing in for the real explainer, to test how an animation reads inside article prose.

How small can a square container be if it must hold n unit squares without overlap? For most n the answer is the obvious grid. For a few it is not, and those few are where the problem becomes interesting.

The animation above is a single SVG file with no JavaScript. It is the same renderer that draws the atlas figures, so the last frame of the film and the atlas picture for that n are the same drawing rather than two that resemble each other.

This page is a mockup. The real explainer is rendered in CI by render_explainer.py, which stamps font geometry before it draws; a local copy of that build renders wrong, which is why it is not shown here. What this page tests is only whether an embedded animation sits correctly in a column of prose.
