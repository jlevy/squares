# Four-Hour Exact R4/R5 and Minus-W Loop

## Context

The square-packing project studies the smallest side length `s(n)` of a square that can
contain `n` nonoverlapping unit squares.
This run worked on `n = 5`, where the numerical and exact records expose terminal
configurations that look alike under several coarse identifiers but whose connection
through valid configurations is not known.

The owning open question, [H-023](../hypotheses/H-023-n5-terminal-connectivity.md), asks
whether the ambiguous `n = 5` terminal rows belong to one connected terminal component.
The four-hour window addressed two smaller local questions.
First, it tested six exact rotating-release paths in the `R4` and `R5` direction
families. It then began testing whether the canonical pure minus-`W` direction has a
second-order obstruction.
The run did not attempt to settle global `n = 5` connectivity.

## Outcome

The run accepted one narrow mathematical result: six endpoint-aware `R4`/`R5` paths,
covering three strata and both owner directions, have exact pathwise feasibility and
positive first-order stress certificates.
The retained replay agrees, and twenty semantic controls fail with their declared
identifiers.

The pure minus-`W` question remained unresolved.
Independent reviews stopped three unsound or incomplete instrument versions before they
could produce a target claim.
Those stops led to reusable exact jet, row, stress, and sheet evaluators plus a finite
scale-and-mutation design for the next round.
No experiment 045, scale-router implementation, target run, or pure minus-`W` verdict
was created.

## What Worked

- Preregistration made exp-041’s false endpoint criterion a clean rejection instead of a
  post-hoc reinterpretation.
- Independent review stopped exp-040, exp-043, and exp-044 before incomplete instruments
  could support a mathematical claim.
- Exp-042 used exact generation, independent replay, split feasibility and stress
  determinations, and twenty semantic controls.
  Its accepted scope is narrow and explicit.
- Switching from W6 research to W7 pipeline work preserved the target boundary while
  turning failed drafts into reusable exact components.
- Twenty-nine delegated derivations and audits returned terminal receipts.
  The coordinating record remained in the repository, so no result depends on local
  Codex memory.

## What Did Not Work

- Exp-040’s first rotating-release draft did not distinguish pointwise from pathwise
  zero axes and lacked several proof-perimeter guards.
- Exp-041’s repaired criterion was still mathematically false at one endpoint.
  The rejection supplied the correction used by exp-042.
- Exp-043’s apparent pure minus-`W` obstruction was not tied to production rowwise
  curvature or a checked exp-034 acceleration witness.
  Its temporary green run was not promoted.
- Exp-044 did not reach scale routing, typed production mutations, or target execution.
  The pure minus-`W` and H-023 connectivity questions remain open.
- The phase-count cap described by [D-280](../../../defects.md) stopped session 015
  while one hour remained.
  Session 016 recovered that hour explicitly, but the reusable wall-time-aware phase-cap
  policy is still only contained.
