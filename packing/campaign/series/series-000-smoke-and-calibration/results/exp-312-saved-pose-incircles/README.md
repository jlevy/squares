# Saved-pose incircle discriminator

This prospectively registered test checks the exact centres of the saved relaxation
witnesses from the accepted four-corner classification.
Every one of the 95 saved assignments receives all 136 centre-distance checks; equality
at one survives. The test has not run yet.
Source review and controls are described in the
[experiment](../../experiments/exp-312-h-320-saved-pose-incircles.md).

Any rejection concerns only these fixed saved poses.
It cannot exclude an ordinary seventeen-cell state.
An incircle-compatible result would select a separate orientation realization
experiment, not establish a physical packing.
