# Exact disk convexification discriminator

This prospectively registered test reconstructs whole-cell pair difference polygons and
checks the exact squared norm of every extreme vertex.
The target has not run yet.
See the [experiment](../../experiments/exp-314-h-322-incircle-disk-projection.md).

A complete redundant result retires all pairwise incircle convexification and forest
relaxations. Strict cuts select stronger mathematical work.
Ordinary pair exclusions require a separate consumer and admission; this experiment
changes no census or bound.
