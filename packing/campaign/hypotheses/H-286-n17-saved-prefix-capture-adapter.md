# H-286: Saved-Prefix Capture Adapter

This control consumes the accepted full-17 endpoint prefix from exp-266. It does not
consume the closed tail-A node or produce another owner update.
The descriptor binds the producer receipt, canonical seed/node IDs, complete named state
and label assignment, and accepted root packet.
Its `root` must match both the fresh accepted loader and `producer_receipt.inputs.root`.

The original `capture_cap: null` remains explicit.
The adapter checks the affine field wall equality with normalized inner cap $U$: offset
zero, bounds $Bh$ and $B(U-h)$. Every declared seed-row `wall_lines` must also agree.
Cells, scale and D4 actions stay identical under that normalization.

Acceptance requires bounded gzip loading, streamed node consumption through EOF, fresh
no-producer saved replay of the same content IDs, complete one-step stall and all 17
endpoint center/chart boxes retained over the full accepted root inclusion.
Every derived coordinate, slider and half-angle interval must contain zero.
Direct $v^*\cdot(r_9-r_9^*)$ is evaluated on original polygon vertices and remains
supplementary; it does not change the 29-coordinate maximum or clip $b$.

A valid `unresolved` geometric status passes readiness.
It proves no local, wide, apex or patch predicate by default, and supplies no capture
tree, exclusion, ledger admission or side bound.
Conditional terminal semantics remain those of the existing consumer; original centered
containment is still an inherited premise.
