# Lazy Catalogue and Complete Archives

The retained instrument counted the generated default page, its classic browser script
and its compact index JSON. CSS, shared navigation, theme code and favicon are contained
in the page. The baseline is the preserved complete HTML from the preceding publication
checkpoint; its location, actual source revision, dirty working-tree state, command,
interpreter and recording time are captured automatically in the measurement receipt.

The byte counts are deterministic observations, so no timing distribution is claimed.
The independent projection guard compares all original fields recursively without
calling the exporter.
It restores main and nested-note coefficient payloads, preserves integer strings and
refuses missing files or any changed metadata or coefficient.
Redundant polynomial text and LaTeX remain in the complete archive.

Required Chromium tests cover initial laziness, paged coefficients, errors and retries,
clipboard fallback, late-request selection races, mobile layout and legacy case links.
An independent Astra review also tested real canonical payloads for n=50, 69, 83, 210,
259 and 1850. Historical source-invalid records disclaim packing bounds; mixed source
flags, approximated decimals and unchecked root ordinals retain their meanings.

No certificate computation is repeated by the browser.
The PDF remains the complete archival edition, and the browser does not claim to reduce
its size or prove new optima.
