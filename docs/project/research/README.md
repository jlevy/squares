analogies, and speculation.

consolidated reference list.

## Suggested Reading Order

Read the Chaitin and Ruliad reports first for the two programs’ definitions and
histories.
The foundations-of-physics report assumes that background and focuses on their
intersection rather than repeating it.
The Levin report is independent but cross-references the Chaitin report where
algorithmic information and structured genotype–phenotype maps overlap with evolutionary
questions.

## Maintenance

Reports carry research and last-updated dates because the literature and assessments can
change. Revisions should preserve the distinction between proved results, conditional
constructions, analogies, and philosophical claims.
New factual claims should cite primary or authoritative sources near the relevant text.
