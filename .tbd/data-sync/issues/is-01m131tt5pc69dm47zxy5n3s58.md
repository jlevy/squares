Step 2 of the six-step symbolic promotion route, and the single thing standing between 'exact at n=11' and 'exact at n=29'.

n=11 is exact because Trump published the degree-8 minimal polynomial in 1979; cases/trump11/derive_field takes 'only the published minimal polynomial' and re-derives u = tan(a/2) from it. Steps 2-5 were done by a person decades ago and this repository picks up at step 6. n=29 has no such publication, so only the robust rational route is available, and it explicitly does not certify the source pose.

Scope: given a numerical pose with declared precision, decide which corner touches which edge, which corner touches which wall, and which squares share an angle class -- and report every incidence it cannot decide rather than choosing.

The hard requirement is the failure mode, not the success mode. Step 2 decides that a residual separation at the solver floor (D-021, about 1e-11) is exactly zero. It might not be, and nothing downstream rechecks it. Ambiguous near-contacts must be an explicit typed refusal naming the first undecidable incidence; a guess that looks like an answer is the exact shape of the flattering soundness defects already logged here.

Calibrate on n=11, where the true contact structure is known from the literature, before pointing it at n=29 where it is not.
