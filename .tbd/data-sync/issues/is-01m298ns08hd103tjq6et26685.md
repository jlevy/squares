Two tidy-ups left by the parallel conversion, both mechanical, neither urgent.

**Five probe bodies are byte-identical across directories**, because ownership during the conversion was per-checker:

    candidate/set_capture.js        legend/set_capture.js
    legend/pairs.js                 revision6/pairs.js      revision7/pairs.js
    revision6/api_names.js          revision7/api_names.js
    candidate/state.js              revision6/state.js
    candidate/progress_bar_gone.js  revision7/progress_bar_gone.js

`probes/README.md` says names are grouped by subject so two checkers asking the same question ask it with the same file. Move these into the topic directories that already exist -- `api/`, `pairs/`, `page/`, `dom/` -- and point all four checkers at them.

**And two naming conventions are in the tree**: the gate's probes are kebab-case (`index-of-n.js`, `api-names.js`), the other four checkers' are snake_case (`set_capture.js`, `progress_bar_gone.js`). Pick kebab, which is the convention for files served to a browser and the one the majority of the topic directories already use. Use repren with a pattern file rather than a shell loop.

`check_probes.py` is what says the result is still whole: every name answered, every file named.
