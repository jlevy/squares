Two concrete inconsistencies, both instances of the glossary-audit problem in think-8vhj. (1) README writes 'H-11-H-15'; SYNOPSIS and the artifacts write zero-padded 'H-011'-'H-015', which is the scheme conventions.md defines. (2) README calls T-2 'one verified theoretical result'; SYNOPSIS records T-2 as tier 'proved', instantiated at 'polished'. 'verified (f64)' is a defined tier meaning floating-point evidence and not a proof, so README both understates the result and misuses a tier word.
