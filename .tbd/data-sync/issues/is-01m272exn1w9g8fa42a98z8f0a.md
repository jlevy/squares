Map row 10. devtools/run_projection_ratchet.match_targets currently requires equal counts. The ascent needs n squares matched against n+1 targets. scipy's linear_sum_assignment already handles a rectangular cost matrix; what it needs is a rule for which target is new, and the honest one is whichever the assignment leaves over.

Without this the ascent cannot build a step at all, because every step changes n by one.
