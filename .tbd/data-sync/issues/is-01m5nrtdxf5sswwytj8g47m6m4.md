## Notes

2026-10-24 coord-intake-1023, from #756 review A7 (https://github.com/jlevy/squares/pull/756#issuecomment-6378226088). Since #761, atlas/regularized/n-N.svg is every count's Regularized-mode picture: its default picture in canonical pose. Wherever no regularized view exists, that address serves the house drawing turned to its canonical pose, and main's alt text there reads "Regularized packing". After #756 that is 260 of 324 addresses (255 on main). The owner's rule (23 October): "there is only the concept of a regularized or not-regularized drawing ... We should track regularization separately ... so that we can see the pre-regularized and regularized versions". The question for this work's owner: does a canonical pose alone count as regularized for that address and its label, or should those addresses and alt texts say "canonical pose, not regularized"? The intake pass does not change it; this work owns it.
