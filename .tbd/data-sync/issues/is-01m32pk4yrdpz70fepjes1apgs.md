Second instance of the same detector gap, both found 2026-09-21.

The currency review quoted check_generated_markdown's BANNER value verbatim in its prose -- as prose, discussing the detector -- and the detector then classified the review itself as a generated view. Worked around by naming the constant instead of quoting its value.

The first instance, from the currency audit: check_generated_markdown matches the literal string 'GENERATED by', so docs/tbd/README.md (which says 'Generated by') is invisible to it. Latent today only because flowmark leaves that file byte-identical.

So the detector both over-matches (any document quoting the banner) and under-matches (any generator using different capitalisation). A document that discusses the generation machinery cannot currently be written without tripping it, which is a real constraint on the repository's own documentation.
