Phase 4. The embeddable artifact: a PackingStrategy trace in, one self-contained animated .svg out, using SMIL or CSS keyframes over the frames the trace already carries. No build step, no framework, no JavaScript -- so it works inline, in an <img>, or in a static-site build. The explainer site is its first consumer.

This is the strictest of the four consumers and therefore the one that should decide the renderer's design: a renderer that can emit a standalone animated SVG can trivially serve the workbench, the atlas view and the capture path, while one built for the workbench first would not.

Must refuse to emit a frame from a guide phase without its label, so a directed animation can never be mistaken for a search result. Depends on the renderer-extraction bead.
