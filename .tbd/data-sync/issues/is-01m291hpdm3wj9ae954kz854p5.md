Done in 4ed60b89, recorded for the reasoning.

Every number on the bar is set the same -- sans, small, one weight, tabular figures -- and the colour is the only thing that says which bound it is: scarlet for the proved lower bound, green for the best known upper bound, ink for anything that is neither. The same three colours name the values in the panel, so a reader who has learnt the code on the bar has learnt it for the facts.

Each bound points at the track from the side a reader reads it from: green down from above, scarlet up from below. That separates them vertically, so the two values can no longer collide and neither has to step aside for the other -- which the old layout needed a dodge rule for. The live pointer became a line through the track rather than a third arrow: it is the only mark that moves, so it does not need a shape to argue for it.

The scale's ends carry their formula and their value together -- sqrt(n) 5.10, sqrt(n) + 1 6.10 -- because a scale with no numbers on it asks a reader to take its span on trust.
