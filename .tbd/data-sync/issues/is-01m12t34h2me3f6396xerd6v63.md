tests/test_validation_cli.py::test_run_timeout_terminates_child_and_reports_captured_output fails intermittently in the full suite with FileNotFoundError reading the child.pid file it expects the spawned process to have written, then passes 4/4 times when run alone. It is a race between the test and the child process writing its pid, exposed by parallel load. Make the test wait for the pid file rather than assuming it exists.
