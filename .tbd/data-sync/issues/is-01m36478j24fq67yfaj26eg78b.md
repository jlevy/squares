X-045's structural endpoint audit found that sqpack.field FieldElement.decimal formats through fixed-point Decimal text and strips trailing zeros, so a nonzero value with a sufficiently small exponent can render as an empty string or lose its exponent-scale meaning. The original receipt packing/cases/w3_lower_bound_directions/structural-endpoint-audit.json records the bad display; packing/cases/w3_lower_bound_directions/structural-endpoint-audit-corrected.json records the corrected audit display from an explicitly approximate fixed-point Decimal midpoint. Exact algebraic signs and rational enclosures were unaffected. This research PR must retain both receipts and mark the first superseded; it must not change shared field.py. Done when field.py preserves nonzero exponent-scale values with a regression test and downstream display contracts are reviewed.
